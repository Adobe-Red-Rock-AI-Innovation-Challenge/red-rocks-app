with each question. Write facts the team has checked, one topic per file, and add the source.

Good files to add: `faq.md`, `schedule-2027.md`, `packages.md`, `case-studies.md`, `nil-rules.md`.

Keep the whole folder short (a few pages). Redeploy after a change.
